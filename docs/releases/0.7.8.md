## Updates

- Adopt the pinned Bash container-release workflow with private token files, verified AMD64/ARM64 images, digest-bound Git tags, and guarded Gitea package association.
- Add authoritative root version metadata and documented local release regression checks.
- Support digest-pinned Compose deployment while preserving legacy image-tag selection and the default latest image.
- Preserve the standalone application, Prisma migrations, Chromium, non-root runtime, health check, and persistent book/cover storage.
- Document publication prerequisites, uncertain-write recovery, and inherited upstream publication warnings. This release note does not claim a live publication or successful runtime verification.
